# Power Platform solution source

The final tenant-created solution should be exported here using current Power Platform ALM tooling.

Why this repository does **not** contain a fabricated `.msapp` or fake solution zip:

- Canvas app source (`*.pa.yaml`) is generated by Power Apps Studio / Git integration; Microsoft documents it as source-control output rather than a hand-authored portable app format.
- Modern cloud-flow solution source is best obtained from the environment using Dataverse Git integration or `pac solution clone`.
- Connection references, AI Builder model bindings, environment variables and user identities must be created/bound in the actual tenant.

After the solution is built in your developer environment:

```powershell
./deployment/export-solution.ps1 -EnvironmentUrl "https://YOURORG.crm.dynamics.com"
```

Commit the generated YAML solution source. This gives reviewers genuine Power Platform assets instead of hand-written files pretending to be exported components.
